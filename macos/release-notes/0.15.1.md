**Game data downloads hold on through a shaky connection.**

- **A Wi-Fi drop is ridden out:** when the connection goes away mid-download, Hearthside keeps the bytes it has, waits for the network to come back, and picks up where it stopped.
- **A busy server is waited out:** when the download server asks for a short pause, the download waits and carries on by itself. A longer pause is told plainly, with the time to try again when the server gives one.
- **Forever passwords stay where they were:** the passwords saved for Play are still in your Keychain and still sign in.
