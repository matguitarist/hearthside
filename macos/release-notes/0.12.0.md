**A new icon, and a home server dashboard for both servers.**

- **New icon:** a sword through a W on a globe.
- **The dashboard shows Pandaria too:** Open Dashboard (Server menu) now reports the Classic and Pandaria servers side by side, with a switch between them: who is playing, the bots, memory and CPU, and Pandaria's five continents on its world map.
- **Run the servers from the dashboard:** start, stop or restart either server, back up Classic, and change the bots, rates and Pandaria's world threads, from any browser at home. Anyone at home can still look; changes ask for a password, set in Settings › Home Server › Dashboard Password….
- **Pandaria's settings are kept:** the number of bots (300 by default, down from 500, which saves about 2 GB of memory), their level sync, the world threads and the rates are written into the server's configuration at every start.
