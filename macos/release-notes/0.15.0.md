**Forever keeps up with Blizzard and with ForeverCore.**

- **Update the server from the dashboard:** the home dashboard's Forever page shows when a newer ForeverCore is out. **Update…** builds it on the home server while you keep playing, then stops the game for a few minutes to save and update its databases. If anything goes wrong, the server is put back as it was, and **Go back…** returns to the version before.
- **New game builds just work:** when Battle.net updates Forever, the first Play lets the new build in on your server (it restarts once).
- **Play waits for an update:** while the server updates, the launcher says so, and **Settings › Forever › Update Log** shows its progress.
